You can view past attendance logs using the History tab. Select a date range to see a summary of attendance trends. The application displays these records in a simple table. You can sort this table by date or by student name.

## 🛡️ Data Security
The software saves all files locally on your machine. This means your student data stays on your school computer rather than on a remote server. We recommend you perform a manual backup of your data folder once a week. Save this folder to an external USB drive or a secure network location. 

If you reset your computer, move your data folder to a safe place first. After reinstalling the app, place the data folder back into the application directory to restore your records.

## 🔧 Frequently Asked Questions

**Does the app require an internet connection?**
No. The application functions entirely offline. You do not need Wi-Fi to mark attendance.

**How do I update to a newer version?**
Download the latest installer from the link above and run it. The new version overwrites the old one while keeping your data intact.

**Can I export my attendance records?**
Yes. Use the Export button in the History tab to save your records as a spreadsheet file. You can open these files with common office software.

**What happens if I forget to save?**
The app includes an auto-save feature. It saves your current session every five minutes to prevent data loss.

**Does the app support multiple users?**
Each instance of the app runs for the current Windows user. If your school uses multiple accounts on one computer, each person maintains their own separate set of records.

## 🆘 Troubleshooting
If the app fails to open, verify your Windows version. Ensure you have the latest updates from the Windows Update settings menu. If the icon does not appear on your desktop, search for the app name in the Windows Start menu bar. 

If you continue to encounter errors, check that your antivirus software does not block the application. Some security programs flag new installs. If this happens, add the app to your "Allowed Apps" list within your antivirus settings.
